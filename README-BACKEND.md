# Wawera Backend — preparação

Este ficheiro marca a preparação da arquitetura para a próxima fase da aplicação.

## Objetivo

Separar a interface da Wawera dos dados online e da autenticação real.

## Próxima fase

- autenticação segura
- base de dados online
- utilizadores
- publicações partilhadas
- comentários e gostos
- oportunidades reais

Por enquanto, o frontend continua a usar armazenamento local durante o desenvolvimento.
